# 正则表达式可视化调试器

NFA 状态机可视化、逐步匹配高亮、分组捕获标注、回溯追踪的交互式正则调试工具。

## 技术栈

- Vue 3 + TypeScript + Vite
- Pinia 状态管理
- Tailwind CSS 样式
- Canvas 2D 状态机渲染

## 功能

- 正则表达式 NFA 状态机 Canvas 可视化
- 逐步匹配高亮（字符→状态→转移边）
- 分组捕获实时标注与颜色编码
- 回溯路径追踪与步骤计数
- 20+ 常用模式模板库
- 正则语法树分层可视化
- 匹配性能统计（步骤数/回溯次数/耗时）
- 零宽断言支持：正向/负向前瞻 `(?=…)` `(?!…)`、非捕获分组 `(?:…)`
- 量词 `* + ? {n} {n,} {n,m}`、惰性量词标记（惰性标记可解析，匹配采用最长匹配语义）
- 解析错误即时提示（含出错位置）；错误/空态/无结果/失败重试各区域反馈一致
- 失败时保留用户输入；模板切换与手动输入状态同步，无结果/画布残留

## 引擎说明

- 匹配语义为"在测试字符串中搜索首个匹配"，`^` / `$` 按零宽位置处理
- 暂不支持反向引用（如 `\1`）与后行断言
- 错误状态、匹配结果与 NFA 画布在每次执行时原子更新

